# База знаний AYS Connect

Backend-модуль `knowledge_base` хранит вложенные категории, материалы, неизменяемые версии, теги, правила доступа, просмотры, избранное, назначения ознакомления и метаданные ТТК.

## Доступ

Опубликованный материал без правил доступен всем авторизованным сотрудникам. При наличии правил требуется совпадение по сотруднику, роли, должности, подразделению, объекту или региону. Уровни доступа: `VIEW`, `DOWNLOAD`, `EDIT`, `MANAGE`. Владелец материала и руководящие роли могут управлять материалом.

Файлы не имеют публичных URL. Скачивание выполняется через `/api/v1/knowledge/materials/{id}/versions/{version_id}/download/` после серверной проверки. Размер ограничивается `KNOWLEDGE_MAX_FILE_SIZE_MB`, по умолчанию 50 МБ.

## Версии и ознакомление

Публикация версии снимает признак `is_current` с предыдущей версии и обновляет `current_version` материала. Назначение ознакомления связано с точной версией. Если новая версия имеет `requires_reacknowledgment=true`, для ранее назначенных сотрудников создаются новые назначения, а прежняя история остаётся неизменной.

Назначение может иметь `requires_test=true`. В этом случае подтверждение принимается только после успешной попытки теста курса, урок которого связан с данным материалом.

Метаданные ТТК доступны через `/{id}/ttk-metadata/`; поддерживаются блюдо, категория, бренд, объект, цех, выход, время приготовления, хранение, аллергены, подача, согласующий и эталонное изображение.

## API

- `/api/v1/knowledge/categories/` — категории;
- `/api/v1/knowledge/tags/` — теги;
- `/api/v1/knowledge/materials/` — каталог и CRUD;
- `/{id}/versions/` — история и публикация версии;
- `/{id}/favorite/` — переключение избранного;
- `/{id}/acknowledge/` — подтверждение ознакомления;
- `/required/`, `/recent/`, `/ttk/` — персональные выборки.
- `/{id}/ttk-metadata/` — чтение и управление метаданными ТТК.
- `/api/v1/management/knowledge/acknowledgments/` и `/analytics/` — управленческий контроль.

Интерактивная схема доступна по `/api/docs/`, OpenAPI JSON — по `/api/schema/`.

# Модуль обучения

Backend базового контура реализован в приложении `learning`. Он переиспользует существующих сотрудников, роли, оргструктуру, задачи, инциденты, чек-листы, рабочие материалы и аудит.

## Модель

- `CourseCategory` — вложенный каталог;
- `Course` — версия и жизненный цикл `DRAFT → PUBLISHED → ARCHIVED`;
- `CourseAudience` — правила по сотруднику, роли, подразделению, объекту, должности и региону;
- `CourseModule` и `Lesson` — упорядоченная программа;
- `CourseAssignment` — персональное назначение со сроком и источником;
- `LessonProgress` — открытие, завершение, подтверждение и затраченное время.

## Права и прогресс

Руководящие роли создают и публикуют курсы и назначают сотрудников. Сотрудник получает только собственные назначения. Процент, текущий урок и статус вычисляет backend; прямое изменение этих полей через API запрещено.

## API

- `/api/v1/learning/categories/`;
- `/api/v1/learning/courses/` и `/{id}/publish/`;
- `/api/v1/learning/courses/{id}/modules/` и `/{id}/audience/`;
- `/api/v1/learning/assignments/`, `/my/` и `/{id}/start/`;
- `/api/v1/learning/lessons/{id}/complete/`.

Тестирование и сертификаты реализованы и описаны в `ASSESSMENT_RULES.md`.

## Интеграции

При создании назначения backend всегда формирует уведомление `COURSE_ASSIGNED`. Параметр `create_task=true` создаёт связанную задачу с источником `TRAINING`; успешное завершение курса закрывает её системным переходом и добавляет запись истории.

Команда `python manage.py run_schedules` дополнительно:

- переводит незавершённые курсы и ознакомления в просрочку;
- создаёт однократные напоминания о приближении срока;
- обновляет состояния `ACTIVE`, `EXPIRING`, `EXPIRED` сертификатов;
- создаёт уведомления, которые обрабатываются существующим Telegram mock.

В персональную аналитику добавлены `mandatory_learning_on_time`, `overdue_courses`, `valid_certificates`, `acknowledgment_rate` и `overdue_acknowledgments`. Эти показатели пока не изменяют общий индекс эффективности.

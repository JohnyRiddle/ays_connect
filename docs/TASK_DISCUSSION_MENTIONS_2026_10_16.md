# Блоки вложений/чата и всплывающие упоминания

16.10.2026, локальная реализация; production не менялся.

Дополнение: чат оформлен как переписка. Сообщения в отдельном прокручиваемом
контейнере (role log, доступен с клавиатуры), поле ввода находится под ним.
Сообщения остаются в хронологическом порядке API. При открытии показан низ;
при чтении старых сообщений изменения формы/высоты контента не сбивают позицию.
Успешная собственная отправка прокручивает к новому сообщению. ResizeObserver
следит за содержимым и размером viewport, сохраняя положение у нижней границы
при изменении окна/экранной клавиатуре. @подсказки находятся вне scroll-контейнера
и открываются над полем ввода. История и согласования сохранены.
Итоговый UI gate **16/16 PASS**, дополнительно scroll/resize **2/2 PASS**
на 1280/390 px; TypeScript/Vite/diff PASS. API чата и права не менялись.

Описание, чек-листы, вложения и чат задачи разделены промежутками и отдельными
карточками. Вложения и чат имеют оранжевую верхнюю границу, рамку и заголовок;
ранее общая рамка объединяла содержимое в один длинный блок. Сохранены загрузка,
preview/download изображений, чат, inline @, история и согласования.

Новые упоминания показываются справа сверху у колокольчика, без системных
browser permissions. Карточка содержит заголовок задачи, нейтральный текст,
«Открыть задачу» и закрытие. Автоскрытие 10 секунд, с паузой при hover/focus;
focus не перехватывается, aria-live polite. На телефоне ширина ограничена экраном.
Не больше трёх карточек одновременно; все уведомления остаются в колокольчике.

Опрос непрочитанных — каждые 10 секунд и при focus/возвращении вкладки;
скрытая вкладка не опрашивается, параллельных запросов нет. Первый успешный
ответ устанавливает исходный набор без всплывающего старого backlog. Показанные
IDs учитываются в sessionStorage отдельно для каждого пользователя, с лимитом
500 сохранённых IDs. Закрытие/автоскрытие не меняет read status. Переход вызывает
штатный read endpoint. При следующем ответе исчезнувшие/недоступные упоминания
удаляются из всплывающего набора. Ошибка запроса не создаёт ложное уведомление.

NotificationSerializer получил read-only boolean `is_mention`. Флаг определяется
по исходному task.comment_added/updated и текущему UUID mention, а не поиском
фамилии/текста. Отдельный task.comment_mentioned Outbox event по-прежнему не
создаёт второй notification. Проверяются активность получателя, актуальный
доступ к задаче/объекту и internal comment scope через существующий visible_source.
Удалённый комментарий/упоминание и legacy notification без intent дают false.
Тексты комментариев и новые права в API не выдаются. Список предзагружает intent
и получателя. Миграций, новых событий/каналов и внешних Telegram отправок нет.

## Автоматическое обновление переписки (локальная доработка)

Чат читает существующий scoped comments endpoint раз в 5 секунд и сразу
при focus/возврате видимой вкладки. Скрытая вкладка не выполняет периодические
запросы. Единственный источник состояния useTaskComments исключает конкуренцию
с общим load задачи; own-send ждёт предыдущий GET и выполняет свежий read.
Запросы не перекрываются, timeout 15 секунд; при смене задачи/unmount запрос
отменяется, поздний ответ не меняет другую задачу. Неизменившийся список
не вызывает повторный render. Редактирование/удаление учитываются полным read.

Черновик, выбранные @ и положение чтения сохраняются. У нижней границы новые
сообщения видны автоматически; чтение выше не сбивается. Сетевая ошибка
сохраняет последнюю переписку и показывает status с автоматическим повтором;
401/403/404 очищают сообщения и останавливают опрос до повторного открытия.
Первое чтение выполняется и в фоновой вкладке; следующие — только в видимой.
Backend/API payload/RBAC/Outbox/Telegram не менялись, миграций нет.

Новые browser-сценарии: 1280/390 px, приход без reload, draft и scroll,
восстановление после 503, edit/delete, hidden/visible, медленный GET одновременно
с собственной отправкой и повторные focus без перекрывающихся запросов.
Реализация локальная: commit/push/publication этой доработки не выполнялись.

Итоговый browser gate **19/19 PASS**, TypeScript/Vite/diff check PASS.

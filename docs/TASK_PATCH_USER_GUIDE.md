# Задачи: инструкция сотруднику и руководителю

Новые обращения оформляются задачами. «Заявки» больше нет в меню; исторические
карточки доступны уполномоченным пользователям по прежним ссылкам.

## Сотруднику

1. Откройте «Задачи» → «Создать задачу», укажите название и описание.
2. Выберите объект, если он относится к обращению, и ответственное подразделение.
   Руководитель подставится автоматически. Ошибка настройки означает, что
   администратор должен указать должность руководителя и её активного сотрудника.
3. Выберите приоритет. Критическая — 3 часа, высокая — 24 часа, обычная —
   3 календарных дня, низкая — 7 календарных дней. Отсчёт идёт от создания.
   Блокирующей нужен явный дедлайн. Исполнителя можно назначить позже.
4. В карточке пишите сообщения. В блоке «@Упоминания» найдите и отметьте сотрудников,
   затем отправьте сообщение. Упоминания сохраняются ссылками на Employee.
   Предупреждение «нет доступа» означает, что сообщение не откроет доступ:
   уполномоченный руководитель может добавить сотрудника наблюдателем.
5. Telegram подключается в настройках уведомлений по одноразовой ссылке на
   @AYS_ai_expert_bot. Ссылка действует 15 минут. Отключение отзывает старые коды.
   Для блокировки бота или ошибки доставки показывается отдельный статус.

Telegram будет присылать уведомления и ссылки после подключения API разработчиком
бота. Отвечайте в AYS Connect; ответы из Telegram на этом этапе не поддерживаются.

## Руководителю

В «Переназначить» выберите тип назначения и активного сотрудника подразделения,
имеющего доступ к объекту. Назначение исполнителя не снимает с руководителя
ответственность. Переназначение проверяет ваши действующие права; сама должность
руководителя прав не добавляет. Уполномоченный администратор с global reassign
может выполнить операцию, сохраняя те же границы подразделения и объекта.

В блоке наблюдателей можно выбрать нескольких сотрудников и добавить их;
удаление сохраняет историю. Наблюдение даёт участие через действующие view/comment
policies и не даёт автоматически переназначение, изменение срока или завершение.
Доступ к объекту и вложениям проверяется на сервере. При ошибке добавления частично
добавленная UI-пачка остаётся видимой: остальные записи можно исправить или удалить.

Редактирование подразделения и приоритета доступно в «Основной информации».
При смене приоритета срок пересчитывается от исходного создания; прошедший срок
сразу просрочен. Для перехода в блокирующую сначала задайте явный срок.
Ручной срок меняется отдельным действием с обязательной причиной и аудитом.

В проекте обязателен дедлайн. Новая задача использует объект проекта, если шаблон
не задаёт свой объект. Руководителю и исполнителю нужен явный доступ к объекту.
Приоритета у проектных задач нет; отдельный срок не должен
быть позже проекта. Без своего срока задача использует срок проекта. При сокращении
проектного срока сначала исправьте конфликты незавершённых задач.

## Администратору

Явно настройте подразделения и руководителей через действующие People/Organization
процессы. Новым зарегистрированным сотрудникам после одобрения нужны корректное
членство, активный статус и отдельные реальные grants; трудоустройство не создаёт
доступ автоматически. Не выдавайте глобальные права для обхода ошибки назначения.

У старых задач и шаблонов поле подразделения пустое. Заполните его осознанно:
для задач — авторизованным PATCH с version и административным правом `task.admin`
в нужной области либо global reassign, для шаблонов — действующим API управления
шаблонами. До заполнения старые черновики нельзя публиковать; шаблоны нельзя
материализовать. Возобновление, возврат на доработку и повторное открытие также
проверяют руководителя перед передачей в работу. Старые UUID/targets, записи истории
и grants не мигрируются случайно.
Если руководитель сменился после создания, явно синхронизируйте ответственное
назначение с новым руководителем через reassign; история прежнего назначения остаётся.

Delivered означает подтверждённый Telegram message ID. Pending/processing/retry
означают ожидание, unknown — проверку неоднозначной отправки, failed — остановку.
Не повторяйте unknown без проверки фактического результата в боте.

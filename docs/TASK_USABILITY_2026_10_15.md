## Локальные изменения кода, ещё не опубликованы

- Неблокирующие приоритеты показывают предварительный срок в форме создания,
  используя priority_hours сервера в assignment-options. При отправке точный
  срок вычисляет существующий сервис. Для блокирующей задачи ввод остаётся ручным.
  Если после ручного дедлайна выбрать другой приоритет, старый дедлайн не отправляется.
- Без прикреплённых чек-листов нет заголовка/нулевого прогресса. Управляющий видит
  только свёрнутое действие прикрепления; без управления панель скрыта полностью.
- Уже добавленные наблюдатели доступны в результатах с пометкой «Уже наблюдает»
  и не добавляются повторно. Исходная visibility/object policy не расширялась.
- PNG/JPEG/GIF/WebP открываются в просмотрщике страницы после авторизованной
  загрузки. Отдельное скачивание сохранено, object URL освобождается при закрытии;
  активные SVG/HTML не открываются через этот просмотрщик.
- Отдельная панель упоминаний убрана из чата. @ в тексте открывает подсказки;
  выбор сохраняет прежний Employee UUID, текстовое удаление имени убирает UUID.
  Старые Permission/Audit/Outbox/notification контракты комментариев сохранены.

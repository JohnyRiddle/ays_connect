# Telegram из профиля — 14.10.2026, ожидает доступа сервера к Telegram

Постоянная доставка **не подключена**: обнаружена недоступность Telegram с production-сервера. Подготовленная конфигурация сохранена; канал возвращён в выключенное состояние, входящий receiver остановлен. Семь основных runtime продолжают работать. Задач осталось 0, сотрудники и права не менялись.

## Требуемый пользовательский путь

Сотрудник в своём профиле AYS Connect нажимает «Подключить Telegram», открывает одноразовую ссылку на `@AYS_ai_expert_bot` и нажимает Start. Эта команда связывает его Employee с его личным Telegram. Простое `/start` без ссылки из профиля аккаунт не связывает. Чужие аккаунты вручную не связывались.

Получатель определяется `responsible_employee` задачи, который штатно назначается по руководителю подразделения. У ответственного должен быть подключён Telegram в собственном профиле. Прежние правила PR #3 для исполнителей, наблюдателей и упоминаний сохранены.

Подготовлен transport `direct`: доставка остаётся у существующего notification_worker и Notification/Audit/Outbox. Corporate service API и отдельный pull-sender не используются. Сохранены проверки доступа, активности сотрудника, привязки, настройки каналов и тихих часов. Неопределённый исход отправки становится `unknown` без автоматического повтора. Старые delivery не переоткрывались.

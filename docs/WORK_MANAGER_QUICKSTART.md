# Work quickstart — руководитель

## Сотрудники и аккаунты

Раздел «Сотрудники» ограничен организационным scope. В карточке можно пригласить сотрудника, перевыпустить или отозвать приглашение; raw link доступен только сразу после выпуска. В «Заявках на регистрацию» администратор выбирает подтверждённого существующего Employee — одного совпадения по ФИО недостаточно. Block/unblock управляет User и не заменяет кадровую деактивацию Employee.

- Назначайте ответственного/исполнителя в пределах выданного scope; Global Admin не нужен для обычной работы.
- Контролируйте активные и просроченные задачи, принимайте результат либо возвращайте с конкретной причиной.
- В заявках отслеживайте routing, ожидание, SLA и эскалации. Internal notes не предназначены заявителю.
- Используйте Performance для нагрузки, потока, сроков и SLA; учитывайте размер выборки, ожидание и историческое переназначение. Это не leaderboard.
- При росте очереди или stale worker передайте оператору время и request ID, не копируя приватные payload/log secrets.

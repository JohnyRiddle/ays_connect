# Work quickstart — сотрудник

1. Откройте корпоративный HTTPS-адрес и войдите рабочей почтой. Никому не передавайте пароль или Telegram link token.
2. В «Задачах» видны доступные вам задачи. Откройте карточку, оставляйте комментарии/вложения и выполняйте чек-лист; перед завершением проверьте результат.
3. В каталоге услуг создайте заявку, заполните обязательные поля и отслеживайте статус. При запросе информации ответьте в публичном комментарии.
4. «Уведомления» показывают события Work. Telegram подключается одноразовой ссылкой в настройках и там же отключается.
5. «Эффективность» показывает объяснимые показатели; отсутствие данных не означает нулевую оценку.

При конфликте версии обновите карточку: её изменил другой пользователь. При недоступности сервиса сохраните текст отдельно и сообщите через утверждённый support channel.
